# CineReview
CineReview adalah website informasi film yang membantu pengguna menemukan dan menjelajahi berbagai film populer dengan mudah. Website ini menampilkan poster film, judul, tahun rilis, rating, sinopsis, dan trailer film. Dilengkapi dengan fitur pencarian dan filter berdasarkan tahun, CineReview memudahkan pengguna menemukan film sesuai minat mereka.
